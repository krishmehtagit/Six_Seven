# Six_Seven — Hack the Chip (NYU × Annapurna Labs)

Team repo. **Start with [`TEAM.md`](TEAM.md)**, then pick a task in [`TASKS.md`](TASKS.md). Using an AI assistant? Point it at [`AGENTS.md`](AGENTS.md).
